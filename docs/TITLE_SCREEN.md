# タイトルカッコカリ｜最初の画面の制作方針

更新日：2026-10-01

対象：[Issue #51](https://github.com/shiroku46/title-kakko-kari/issues/51)

共通の実装基準：[UI_DESIGN_SPEC.md](UI_DESIGN_SPEC.md)

## 名前と絵の決定

ユーザーは、作品の本当の題名が分からない間に、仮の題名を付けてだまし合う遊びとして名前を考え直し、「タイトルカッコカリでいきましょう」と指定した。

- 正式名：**タイトルカッコカリ**
- 画像ロゴの表記：**タイトル（仮）**
- アプリ名、ブラウザーの題名、ロゴの読み上げ名：正式名を使う
- 過去の資料や引用元の名前：当時の記録を保持する

最初の画面は、画像生成で用意するロゴとイラストに合わせて作り直す。ロゴと、濃紺の猫1体が扇形の物語カードを持つ絵を、別々の素材として使う。カードは本や映画などの物語を思わせるものにし、遊べる作品を一つの種類に限定しない。

## 画面の要素

| 要素 | 内容・素材 | 扱い |
| --- | --- | --- |
| 小さいロゴ | `GameLogo` compact | ヘッダーに置く。読み上げは正式名 |
| 大きいロゴ | `client/assets/brand/title-logo.png` | 「タイトル（仮）」の生成画像。縦横比を保つ |
| 見出し | ウソの題名をつくって、本物を見ぬこう。 | 実際の文字で表示 |
| 説明 | あらすじを読んで、ありそうな題名を考える。みんなで選んで、答え合わせ。 | 実際の文字で表示 |
| 参加面の見出し | いっしょに遊ぼう | 実際の文字で表示 |
| 入力の説明 | ゲームで使う名前を入れてね。 | 実際の文字で表示 |
| ニックネーム | 既存の名前入力 | ラベル付きの入力欄 |
| 作成 | 部屋をつくる | 主要ボタン |
| 参加 | 部屋に入る | 副ボタン。既存の部屋コード入力へ進む |
| 人数の案内 | 4〜6人で遊べること | 実際の文字で表示 |
| 遊び方／接続設定 | 既存の説明画面と設定の開閉 | 既存の意味と動きを保つ |
| 猫と物語カード | `client/assets/brand/title-cards.png` | 操作できない装飾。読み上げ対象から外す |

サンプルの題名一覧、特徴を並べたカード、英語のkickerは置かない。入力欄とボタンを絵に描いて済ませず、実際に操作できる部品を使う。

## 色と文字

| 用途 | 方針 |
| --- | --- |
| ホームの背景 | 無地のクリーム `#FFF7E8` |
| 見出し・輪郭 | 濃紺 `#0B2D4D` |
| 主なボタン | 生成見本の赤 `#EB4057` と白文字。文字は20px、Bold（700） |
| 副ボタン | 濃紺、または明るい面に濃紺の文字 |
| 絵の差し色 | 赤、黄、水色。文章より目立たせすぎない |
| 本文・入力 | 同梱のNoto Sans JP Regular、400 |
| 見出し・ボタン | 同梱のNoto Sans JP Bold、700 |
| ロゴ | 生成画像。本文の文字を大きくしただけのロゴにしない |

文字はホームだけでなく、ゲーム中の説明、見出し、ボタン、入力欄にも同じRegular／Boldを使う。以前集めた丸い文字や手書き風の文字は別案として保存する。文字の利用条件と変換方法は [FONTS.md](FONTS.md) にまとめる。

## パソコンの配置

背景を広く見せ、左にロゴ、短い説明、猫と物語カードの絵を置く。右に名前入力と作成／参加をまとめた一つの参加面を置く。左側全体を濃紺の箱で囲まない。

画面幅1024px以上で左右に分ける。左右の余白は画面幅の5.75%ずつ、全体の最大幅は1586pxとする。参加面は内容幅の34%で、左に40pxの余白と細い境界線を置く。1440×900では主な情報を一画面に収め、1024×768でも作成／参加が見切れないようにする。画像を縮める必要がある場合は、入力欄とボタンの読みやすさを先に守る。

## スマートフォンとタブレットの配置

幅1024px未満では、次の順に縦に並べる。

1. 小さいロゴと遊び方／接続設定
2. 大きいロゴと短い説明
3. 名前入力と作成／参加
4. 猫と物語カードの絵

左右の余白は20pxとする。主なボタンは面の幅に合わせる。390×844で、作成ボタンが最初の表示または短いスクロールで見えることを目標にする。文字を大きくしても横にあふれないようにし、タブレットでも参加面を絵より先に置く。

## 絵の見本から変えるところ

- スマートフォンでは、参加面を絵より先に置く。すぐに名前を入れて遊びへ進める順にする。
- 生成見本に紙のざらつきや色むらが見えても、実際の背景は正確な `#FFF7E8` の無地にする。見本全体を背景画像として使わない。
- 見出し、説明、人数、入力、ボタンは実際の文字と部品に置き換える。画面の大きさに合わせて改行と間隔を変える。
- ロゴと絵は独立した画像にし、縦横比を保つ。見本の位置をそのまま固定せず、入力と操作のために大きさを調整する。

## 読みやすさと操作

ロゴには「タイトルカッコカリ」の読み上げ名を付ける。猫と物語カードは文章や操作を増やさない装飾として扱う。入力欄にはラベルを付け、ボタンはキーボードでも操作できるようにする。押せる場所は44×44px以上とする。ホームのボタンの最小高さは縦並び56px／パソコン72px、入力欄は縦並び54px／パソコン72pxとする。

本文の色の差は4.5:1以上を基準にする。赤い主要ボタンの白文字は20px、実際のBold（700）を使い、大きい太字の基準で3:1以上の色の差を確保する。押せない状態、接続中、入力の間違いは、色だけで伝えず言葉と状態表示を付ける。文字の読み込みに失敗した場合は端末の文字で開く。部屋の作成／参加、部屋コード入力、遊び方、接続設定、通信、採点、4〜6人の人数条件は既存の処理を保つ。

## 確認項目

以下は実装後に確認する項目であり、完了結果はその時点の変更番号に結び付けて別途記録する。

- 390×844、768×1024、1024×768、1440×900で、ロゴ、絵、文章、入力、ボタンを見比べる
- 作成／参加の切り替え、名前と部屋コードの入力、遊び方と接続設定の開閉を確かめる
- ロゴの読み上げ名、装飾画像の扱い、文字拡大、キーボード操作を確かめる
- Regular／Boldの読み込み、使える日本語、利用条件、読み込み失敗時の表示を確かめる
- Web用の出力と、作業場所での4人の部屋作成からゲーム終了までを確認する
- 見本と実際の画面の差を確認し、意図した変更と修正が必要な差を記録する

## 生成した素材

2026-10-01、画像生成ツールで全体の見本を作り、その見本を元にロゴと猫・物語カードを別々の背景が透明なPNGとして作った。全体の見本を切り抜いて入力欄やボタンの代わりにする方法は使っていない。

| 素材 | 大きさ | bytes | SHA-256 |
| --- | --- | --- | --- |
| ロゴ | 2137×736、RGBA | 750485 | `86fed24e01aba5efe0b3da6b6e7e9667d9d50bf4c04479ae266d5896cfa46289` |
| 猫と物語カード | 1774×887、RGBA | 1341892 | `9119e93d48e08748c49e43dd7158e6207416f145479283d035e94bcf23dd1f47` |

通常の文章は本文4.5:1以上、主ボタンの20px・700の大きな文字は3:1以上を使う。赤い主ボタンは見本と同じ `#EB4057` を保つ。
