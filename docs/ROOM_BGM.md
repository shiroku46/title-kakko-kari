# 部屋のBGM

公開ブラウザー版のBGMは初期状態ではミュートです。「BGMを再生」を押すと「Swing Along / bramd」をループ再生します。初期音量は20%です。
画面下の「ミュート／BGMを再生」と「−／＋」で、自分のBGMを操作できます。音量は10〜100%を10%ずつ調整できます。
音量とミュートはブラウザーに保存され、他の参加者には影響しません。保存できない環境でも、その起動中の設定は使えます。
同じ表示音量での出力は従来の4分の1です。同梱曲・端末MP3の両方に適用します。
以前の設定は音量と同梱曲を引き継ぎ、今回の更新後の初回だけミュートに戻します。その後に選んだ再生・ミュート設定は保存します。

「BGMの曲を選ぶ」で次の4曲を切り替えられます。選んだ同梱曲もブラウザーに保存します。

| 曲 | 種類 | 作者 |
|---|---|---|
| Swing Along | エレクトロスウィング | bramd |
| Pop Rocks | ポップ | Shane Ivers |
| Bumbumbum | レトロポップ | Shane Ivers |
| Lobby Time | ラウンジ | Kevin MacLeod |

「MP3を読み込む」から端末のMP3を選ぶと、自分のブラウザー内で直接ループ再生します。
ファイルはサーバーへ送信せず、ほかの参加者には聞こえません。選択時はミュートを解除し、現在の音量で再生します。
同梱曲への切替では音量・ミュートを維持します。ファイル選択を取り消した場合、再生中の曲は変わりません。
空のファイル・MP3以外の拡張子は拒否し、再生できないMP3はエラーを表示して再試行や別の曲への切替を可能にします。
MP3の内容やファイル名はブラウザーへ保存しません。再読み込み後は前回の同梱曲に戻り、MP3は選び直します。
曲やMP3を切り替えても、同じ1つのプレイヤーを使います。MP3の差し替え・同梱曲への復帰・退出でファイルの参照を解放します。

ブラウザーが自動再生を許可しない場合は「BGMを再生」を押してください。読み込み失敗も同じボタンから再試行できます。
待合室・名前の変更・ゲーム・結果画面では同じプレイヤーを使い、画面遷移や接続復帰で曲が重なりません。
ホームへ戻ると停止して音声を解放します。タブを隠すと一時停止し、戻ったときにミュート設定とブラウザーの許可に従って再開します。

音源はアプリに同梱し、音楽配布サイトへの実行時アクセスや録音の許可は不要です。
追加の実行時依存関係はありません。今回の音声対応は公開ブラウザー版が対象です。
