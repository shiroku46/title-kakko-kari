## BGM検証

- Swing Along（エレクトロスウィング）、Pop Rocks（ポップ）、Bumbumbum（レトロポップ）、既存のLobby Time（ラウンジ）を全て実際にデコードし、音量処理後の音声信号が0でないことを確認。
- 同じAudioContextで曲を切替。MP3読込時にミュート解除。壊れたMP3のエラー、別曲への復帰、差し替え・退出時のファイル参照解放を確認。
- 音量・ミュート・同梱曲の保存、参加者ごとの独立、名前編集・ゲーム・結果をまたぐ継続、通信復帰、ページ再読み込みからの同じ席への復帰を確認。
- 自動再生を拒否するChromiumで案内と再生ボタンを確認。実際の曲末尾からのループを確認。ホームでは音声を作らず、退出時に停止・解放。
- MP3の音声・ファイル名は保存・アップロードしない。再読み込み後は、MP3を再選択する。

音源の正本・作者・利用条件・再圧縮の記録は [音源クレジット](../client/assets/audio/LICENSE.md)。
