# 残り時間と画面通知

回答・投票中は画面上部の中央に残り時間を「分:秒」で大きく表示します。本文をスクロールしても表示位置は変わりません。

- 残り時間が1分単位の境目を通過するたびに、画面に通知を5秒間表示します。
- 残り30秒で黄色の警告表示と「残り30秒」の通知に変わります。
- 最後の10秒は赤い表示と、1秒ごとの「あと○秒」のカウントダウンです。0秒より下には進みません。
- 音、点滅、ポップアップ、ブラウザーの通知は使いません。通知文は画面読み上げにも対応します。

時刻はサーバーから受け取った既存の締め切りから毎回計算します。画面が一時停止していた場合、過去の通知を連続再生せず、現在の残り時間に戻ります。
ラウンド・回答/投票・締め切りの変更ではタイマーと通知をリセットし、退出時は停止します。制限時間なしではカウントダウンや通知を出しません。

同意式の進行で回答/投票が揃った場合は「受付終了」と表示して通知を止め、既存の「投票へ進める／正解を発表する」操作を残します。
0秒になっても次の段階へ進める判断はサーバーと既存の同意設定に従います。クライアントの表示タイマーだけでゲームを進めることはありません。
