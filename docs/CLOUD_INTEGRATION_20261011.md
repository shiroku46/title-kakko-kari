## 反映先と残件

対象は既存のGitHubリポジトリ、Vercelの`title-kakko-kari`、Renderのゲームサーバーです。新規の権限、OAuth許可、Secret設定、課金、DB購入、外部エージェント連絡は行いません。

**本番の永続ストアは不足しています。** ファイル保存は単一プロセス向けです。保存領域を残したローカル再起動の復帰と、Render Freeの休止・再デプロイ・インスタンス交換後の復帰は別です。残る保存先が設定されるまで、後者を保証しません。

実ログインにはプロバイダー登録と許可された接続情報、認証の保存先が必要です。仮のアカウントやボタンだけのログインを実装済みとは扱いません。

実機iOS/Android、読み上げ機器、公開環境の多数同時部屋は未確認です。公開後の反映確認はPRのmerge SHA、Vercel deployment、Render `/health`のrelease、公開画面を突き合わせて記録します。
